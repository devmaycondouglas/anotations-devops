## Sobre o projeto:

Este projeto foi criado com o intuito de ser um "bloco de anotações" sobre os estudos de devops. Para compartilhar com a galera que está querendo começar na área e também para futuras resivões. Todo o conteúdo que estou colocando neste projeto é referente aos estudos que estou fazendo para aprender DevOps e sua cultura. Então é essas anotações são ideais para quem realmente está começando e quer ver como funciona e como estou realizando os estudos. E claro, para quem está lendo, espero que este conteúdo ajude bastante e consiga contribuir com sua jornada!

Lembrando que estou realizando algumas anotações dos meus estudos durante a minha pós-graduação em DevOps também, então haverá algumas pastas referente aos módulos deste meu curso.
